Privacy Policy

Last updated: October 28, 2026

This policy explains how Explica Miúdo (the "application") uses data. The application is an internal tool, used exclusively by Explica Miúdo, that publishes videos produced by Explica Miúdo on Explica Miúdo's own channels (YouTube @explicamiudo and Instagram @explicamiudo).

1. Who uses the application

Only Explica Miúdo itself. The application is not offered to the public, has no user sign-up and does not access other people's accounts.

2. What data we access

With the channel owner's authorization, through the YouTube API Services, the application accesses only the Explica Miúdo account in order to:

  • upload videos produced by Explica Miúdo to the Explica Miúdo channel, with title, description and publishing settings;
  • read the public and performance statistics of the channel's own videos (views, likes, comments), used to improve future videos.

We do not collect third-party data. The application does not read, store or share personal data of viewers, subscribers or anyone else.

3. How we store data

Access credentials (tokens) are stored privately on Explica Miúdo's server and are never published or shared. Channel statistics are kept in an internal database, used only to analyze the channel itself.

4. Sharing

We do not sell, rent or share data with third parties. Data obtained through Google APIs is used in accordance with the Google API Services User Data Policy, including the Limited Use requirements.

5. YouTube and Google services

The application uses the YouTube API Services. By interacting with Explica Miúdo content on YouTube you are also subject to the YouTube Terms of Service and the Google Privacy Policy.

6. How to revoke access

The application's access to the Google account can be revoked at any time at myaccount.google.com/permissions. When that happens, the stored tokens stop working and are deleted.

7. This website

This website is static, uses no cookies, has no forms and uses no tracking tools.

8. Contact

Questions about this policy: send a direct message to @explicamiudo on Instagram.
