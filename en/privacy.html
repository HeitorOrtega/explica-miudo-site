Privacy Policy

Last updated: October 29, 2026

This policy explains how Explica Miúdo (the "application") uses data. The application is an internal tool, used exclusively by Explica Miúdo, that publishes videos produced by Explica Miúdo on Explica Miúdo's own channels (YouTube @explicamiudo and Instagram @explicamiudo) and tracks how those videos perform.

1. Use of YouTube API Services

The application uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API). By using the application, or by interacting with the content it publishes on YouTube, you agree to be bound by the YouTube Terms of Service. Data obtained through YouTube API Services is also subject to the Google Privacy Policy.

2. Who uses the application

Only Explica Miúdo itself. The application is not offered to the public, has no user sign-up and does not access other people's accounts.

3. What data we access

With the channel owner's authorization (Google sign-in with OAuth), the application accesses only the Explica Miúdo account, with these scopes:

  • youtube.upload: upload videos produced by Explica Miúdo to the Explica Miúdo channel, with title, description and publishing settings;
  • youtube.readonly: confirm which channel was authorized (channel name and ID) and read the data of the channel's own videos (ID, title, link, status);
  • yt-analytics.readonly: read statistics of the channel's own videos (views, likes, comments, watch time and retention), used to improve future videos.

We do not collect third-party data. The application does not read, store or share personal data of viewers, subscribers or anyone else.

4. What we store and for how long

  • Access credential (OAuth token): stored privately and encrypted on Explica Miúdo's server until access is revoked. It is never published or shared.
  • Channel video data (ID, title, link, publishing date): kept while the video is on the channel, to link each video to its statistics. Deleted within 30 days after the video is removed from YouTube.
  • Video statistics (aggregated numbers, no personal data): collected 24 hours and 72 hours after each upload and refreshed at least every 30 days. Statistics that are no longer refreshed are deleted within 30 days.

When access is revoked, all data obtained through YouTube API Services is deleted within 7 days.

5. Sharing

We do not sell, rent or share data with third parties. Data obtained through Google APIs is used in accordance with the Google API Services User Data Policy, including the Limited Use requirements.

6. How to revoke access

Access to the Google account can be revoked at any time on Google's security permissions page: security.google.com/settings/security/permissions. When access is revoked, the stored token stops working and is deleted, together with the YouTube data, within 7 days.

7. How to request data deletion

To request deletion of any data stored by the application, send a direct message to @explicamiudo on Instagram with the subject "Data deletion". We confirm the request and delete the data within 7 days. Revoking access (section 6) also deletes the data automatically.

8. This website

This website is static, uses no cookies, has no forms and uses no tracking tools.

9. Contact

Questions about this policy: direct message to @explicamiudo on Instagram.
