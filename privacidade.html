Política de Privacidade

Última atualização: 28 de outubro de 2026

Esta política explica como o Explica Miúdo (o "aplicativo") usa dados. O aplicativo é uma ferramenta interna, de uso exclusivo do Explica Miúdo, que publica os vídeos produzidos pelo próprio Explica Miúdo nos canais do Explica Miúdo (YouTube @explicamiudo e Instagram @explicamiudo).

1. Quem usa o aplicativo

Somente o próprio Explica Miúdo. O aplicativo não é oferecido ao público, não tem cadastro de usuários e não acessa contas de outras pessoas.

2. Quais dados acessamos

Com a autorização do dono do canal, por meio dos Serviços de API do YouTube, o aplicativo acessa apenas a conta do Explica Miúdo para:

  • enviar vídeos produzidos pelo Explica Miúdo para o canal do Explica Miúdo, com título, descrição e configurações de publicação;
  • ler as estatísticas públicas e de desempenho dos vídeos do próprio canal (visualizações, curtidas, comentários), usadas para melhorar os próximos vídeos.

Não coletamos dados de terceiros. O aplicativo não lê, armazena nem compartilha dados pessoais de espectadores, inscritos ou de qualquer outra pessoa.

3. Como guardamos os dados

As credenciais de acesso (tokens) ficam guardadas de forma privada no servidor do Explica Miúdo e nunca são publicadas nem compartilhadas. As estatísticas do canal ficam em um banco de dados interno, usado só para análise do próprio canal.

4. Compartilhamento

Não vendemos, alugamos nem compartilhamos dados com terceiros. Os dados obtidos pelas APIs do Google são usados de acordo com a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Serviços do YouTube e do Google

O aplicativo usa os Serviços de API do YouTube. Ao interagir com o conteúdo do Explica Miúdo no YouTube, você também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

6. Como revogar o acesso

O acesso do aplicativo à conta do Google pode ser revogado a qualquer momento em myaccount.google.com/permissions. Quando isso acontece, os tokens guardados deixam de funcionar e são apagados.

7. Este site

Este site é estático, não usa cookies, não tem formulários e não usa ferramentas de rastreamento.

8. Contato

Dúvidas sobre esta política: mande uma mensagem direta para @explicamiudo no Instagram.
