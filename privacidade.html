Política de Privacidade

Última atualização: 29 de outubro de 2026

Esta política explica como o Explica Miúdo (o "aplicativo") usa dados. O aplicativo é uma ferramenta interna, de uso exclusivo do Explica Miúdo, que publica os vídeos produzidos pelo próprio Explica Miúdo nos canais do Explica Miúdo (YouTube @explicamiudo e Instagram @explicamiudo) e acompanha o desempenho desses vídeos.

1. Uso dos Serviços de API do YouTube

O aplicativo usa os Serviços de API do YouTube (YouTube Data API v3 e YouTube Analytics API). Ao usar o aplicativo, ou ao interagir com o conteúdo que ele publica no YouTube, você concorda com os Termos de Serviço do YouTube. Os dados obtidos pelos Serviços de API do YouTube também estão sujeitos à Política de Privacidade do Google.

2. Quem usa o aplicativo

Somente o próprio Explica Miúdo. O aplicativo não é oferecido ao público, não tem cadastro de usuários e não acessa contas de outras pessoas.

3. Quais dados acessamos

Com a autorização do dono do canal (login do Google com OAuth), o aplicativo acessa apenas a conta do Explica Miúdo, com estas permissões:

  • youtube.upload: enviar vídeos produzidos pelo Explica Miúdo para o canal do Explica Miúdo, com título, descrição e configurações de publicação;
  • youtube.readonly: confirmar qual canal foi autorizado (nome e ID do canal) e ler os dados dos vídeos do próprio canal (ID, título, link, status);
  • yt-analytics.readonly: ler as estatísticas dos vídeos do próprio canal (visualizações, curtidas, comentários, tempo de exibição e retenção), usadas para melhorar os próximos vídeos.

Não coletamos dados de terceiros. O aplicativo não lê, armazena nem compartilha dados pessoais de espectadores, inscritos ou de qualquer outra pessoa.

4. O que armazenamos e por quanto tempo

  • Credencial de acesso (token OAuth): guardada de forma privada e criptografada no servidor do Explica Miúdo, até o acesso ser revogado. Nunca é publicada nem compartilhada.
  • Dados dos vídeos do canal (ID, título, link, data de publicação): guardados enquanto o vídeo estiver no canal, para ligar cada vídeo às suas estatísticas. Apagados em até 30 dias depois que o vídeo é removido do YouTube.
  • Estatísticas dos vídeos (números agregados, sem dados de pessoas): coletadas 24 horas e 72 horas depois de cada publicação e atualizadas pelo menos a cada 30 dias. Estatísticas que deixam de ser atualizadas são apagadas em até 30 dias.

Quando o acesso é revogado, todos os dados obtidos pelos Serviços de API do YouTube são apagados em até 7 dias.

5. Compartilhamento

Não vendemos, alugamos nem compartilhamos dados com terceiros. Os dados obtidos pelas APIs do Google são usados de acordo com a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Como revogar o acesso

O acesso do aplicativo à conta do Google pode ser revogado a qualquer momento na página de permissões de segurança do Google: security.google.com/settings/security/permissions. Quando isso acontece, o token guardado deixa de funcionar e é apagado, junto com os dados do YouTube, em até 7 dias.

7. Como pedir a exclusão dos dados

Para pedir a exclusão de qualquer dado guardado pelo aplicativo, mande uma mensagem direta para @explicamiudo no Instagram com o assunto "Exclusão de dados". Confirmamos o pedido e apagamos os dados em até 7 dias. Revogar o acesso (seção 6) também apaga os dados automaticamente.

8. Este site

Este site é estático, não usa cookies, não tem formulários e não usa ferramentas de rastreamento.

9. Contato

Dúvidas sobre esta política: mensagem direta para @explicamiudo no Instagram.
